# 🚀 React App Deployment Project

This project showcases a complete DevOps pipeline for deploying a React application using:

- **Docker**
- **Jenkins**
- **AWS EC2**
- **Docker Hub**
- **Prometheus Monitoring**
- **GitHub** for source control

---

## 🔧 Tech Stack

- **Frontend**: React.js
- **Containerization**: Docker
- **CI/CD**: Jenkins
- **Cloud**: AWS EC2 (Amazon Linux)
- **Monitoring**: Prometheus
- **Repo Hosting**: GitHub
- **Registry**: Docker Hub
